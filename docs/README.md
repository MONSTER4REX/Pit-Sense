# Documentation

[`../PitSense_PRD_v2.docx`](../PitSense_PRD_v2.docx) is the single source of truth
for this build. Everything in this folder either explains how the build meets it
or is machine-generated evidence that it does.

## Written

| Document | What it is |
|---|---|
| [`Architecture_Audit.md`](Architecture_Audit.md) | What was real versus assumed in the pre-v2.0 build, and what changed. Kept as the record of the PRD §11 Gate 1 audit. |
| [`Submission_Notes.md`](Submission_Notes.md) | What shipped, the validation results, what was deliberately not built, and the known limitations. |

## Generated evidence

Each file is the output of a script under `backend/scripts/`, regenerated by
re-running it. They are committed so the claims in the README and submission
notes can be checked without running anything first.

| File | Produced by | Covers |
|---|---|---|
| [`validation_report.json`](validation_report.json) | `scripts.validation_report` | PRD §13 validation suite |
| [`tyre_model_comparison.json`](tyre_model_comparison.json) | `scripts.tyre_model_report` | PRD §5.J two-model comparison |
| [`feasibility_geometry.json`](feasibility_geometry.json) | `scripts.geometry_feasibility` | PRD §5.G circuit and pit-lane geometry gate |
| [`feasibility_energy.json`](feasibility_energy.json) | `scripts.energy_feasibility` | PRD §5.K energy / ERS gate |

## A note on scope

The four-source **ML / Simulation / History / Memory** intelligence blend that
appeared in earlier planning material is **not implemented and not displayed**.
PRD v2.0 §2.2 scopes it out explicitly as a Phase 2 direction. The factor
breakdown in the running app shows only the four factors the engine computes, and
says so on screen. Earlier planning documents that described it have been removed
rather than left in the repository to contradict the PRD.
